# tools/ — エージェント（ルーティン）の置き場

生成AI横並び検証室を回している Claude のエージェント。1体ずつフォルダを分け、各フォルダの `README.md` が手順書。
ルーティン（claude.ai の自動実行）は起動するとまず自分の README を読み、そのとおりに動く。共通の決まりは [`common/conventions.md`](common/conventions.md)。

| # | 名前 | 仕事 | 起動 | 場所 |
|---|---|---|---|---|
| 1 | ハブ更新（検証記事） | noteに新しい検証記事が出たら、ハブ（このサイト）に載せるPRを作る。Skyがマージ | Skyが起動（記事を出したあと） | [`hub-agent/`](hub-agent/) |
| 2 | 集計（6媒体） | 5つのSNS・GA4・00Min・note（検証室・コタロウ）の数字を読み、ダッシュボードに記録し、図版4枚を書き出し、報告する | Skyが起動 → 安定したら定時 | [`keisoku-agent/`](keisoku-agent/) |

## 決まり（要点。全文は `common/conventions.md`）

- **このリポジトリはサイト。エージェントは読むだけ。** 書き込むのは1体目の `index.html` だけで、それもPR経由
- **秘密・非公開のものはここに書かない**（URL・メールアドレス・ID・パスワード・トークン）。起動時の指示文（非公開）に置く
- 数字はダッシュボードのDB、図はアーティファクト、報告は通知。リポジトリに数字を書き戻さない
- `tools/` は `_config.yml` でサイトの配信から外してある（GitHub上では見える）
