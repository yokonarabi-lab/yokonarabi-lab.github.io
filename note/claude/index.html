結論

最優先は、すべての記事に内容に合った見出し画像を付けることです。経路の方針は「役割を分けて併用」で、noteの中・外部の検索エンジン・外部SNSを使い分けます。見出し画像は、今回確認した公式の資料の中で、ページビューの差を示して勧められていた施策です（画像の有無で比べた統計で、経路別の内訳はありません）。連載の続きやお題に合う記事は、マガジンやハッシュタグでnoteの中に届けます。あとから調べられる疑問に答える記事は、内容が想像できる題で検索に備えます。自分のSNSの読者に関係の深い記事は、要約を添えて告知します。三つの経路の効果を比べた資料はなく、noteの中の裏づけは表示までです。SNSに読者がいなければnoteの中と検索に絞り、経路別の比較が示されれば、この結論は変わります。

C1　見出し画像を付ける

  • タイミング：公開するとき
  • 理由：公式は、noteの投稿データでは見出し画像がある記事は読まれやすく、ページビューやスキ数に数十パーセントの差がつくようだと説明し、すべての記事に付けるよう勧めています。見出し画像は、タイムラインや一覧で目を留めてもらうためのものだとも説明しています。
  • ページビューへのつながり：直接
  • 根拠の種類：公式
  • 直接いえることか：直接いえること（公式の推奨）。統計は画像の有無で比べた相関で、時期・件数・比べ方は示されていません。
  • 実行例：旅行の記事なら、その旅先で撮った写真を横2：縦1の比率に切り抜いて見出し画像にする。
  • 条件と限界：公式の統計は、付ければ増えるという実験ではなく、経路別の内訳もありません。内容と無関係な画像でページビューを稼ぐやり方は、公式が勧めていません。2025年11月4日以降は、見出し画像がなくても、本文の無料部分にある最初の画像または埋め込み動画がnoteの中のサムネイルに使われるため、差の出方が変わっている可能性があります。この自動表示は、SNSで共有したときの画像には反映されません。主な経路「複数」の内訳は、noteの中の一覧（タイムライン、ハッシュタグページなど）と、SNSで共有されたときの表示です。
  • 対応する公式出典：O7・O8・O53

C2　題で内容を示す

  • タイミング：公開するとき
  • 理由：公式は、記事が何について書かれたかをタイトルに入れると興味を持ってもらいやすくなり、長さは15〜25文字程度が目安で、長すぎると一覧やXで省略されてクリックされにくくなると説明しています。note編集部は、題から記事の内容が想像できると、ウェブ検索の結果でもクリックされやすくなると説明しています。
  • ページビューへのつながり：直接
  • 根拠の種類：公式
  • 直接いえることか：直接いえること（公式の推奨）。効果を測った数字は示されていません。
  • 実行例：「旅の記録」を「雨の金沢1泊2日、歩いて回れた3か所」に変える。
  • 条件と限界：記号で無理に目立たせること、数字や疑問形を入れるだけの小手先は、公式が勧めていません。誇張やあおる言葉も、避けるよう助言されています。読者が検索しそうな言葉を入れる勧めはありますが、検索の順位がどれだけ上がるかは示されていません（T12）。主な経路「複数」の内訳は、noteの中の一覧、外部SNSで共有されたときの表示、検索エンジンの検索結果です。
  • 対応する公式出典：O8・O49

  • タイミング：公開したあと
  • 理由：公式は、noteのフォロワーだけでなくSNSにもシェアすると、新しい読者に記事を知ってもらえると説明し、タイトルとURLだけでなく要約やコメントを添えるよう勧めています。ページビューが急に増える要因の一つとして、SNSで紹介されたことも挙げています。
  • ページビューへのつながり：直接
  • 根拠の種類：公式
  • 直接いえることか：直接いえること（公式の推奨）。効果を測った数字は示されていません。
  • 実行例：公開後、記事の要点を2〜3行にまとめ、記事のURLと一緒に自分のXに投稿する。
  • 条件と限界：SNSに読者がいない場合の効果は小さいと考えられます（推論）。SNSでの告知がnoteの中のおすすめを増やすという裏づけはありません（T29）。SNSの投稿そのものを伸ばす方法は、この資料の対象外です。
  • 対応する公式出典：O7・O16・O44

C4　合うタグを付ける

  • タイミング：公開するとき
  • 理由：公式は、ハッシュタグを付けるとnoteの中で記事を知ってもらえる機会が増え、記事の内容に合ったタグを選ぶことが読んでもらう機会を増やす近道だと説明しています。個数は3〜5個程度が目安です。
  • ページビューへのつながり：間接
  • 根拠の種類：公式
  • 直接いえることか：直接いえること（表示や認知まで）。ページビューを測った数字は示されていません。

C5　記事下の相互表示

  • タイミング：書く前
  • 理由：公式は、この設定をオンにすると、自分の記事の下に他のクリエイターの記事が表示され、その代わりに、他のクリエイターの記事の下に自分の記事が薦められるようになると説明しています。記事の下の関連記事に表示された分は、インプレッションに数えられます。
  • ページビューへのつながり：間接
  • 根拠の種類：公式
  • 直接いえることか：直接いえること（表示まで）。どれだけ開かれるかは示されていません。
  • 実行例：ブラウザでアカウント設定のユーザー設定を開き、この項目にチェックが入っているかを確かめる。
  • 条件と限界：初期設定がオンかオフかは確認できていません。すでにオンなら作業はありません。オンにすると自分の記事の下に他の人の記事が並ぶため、読者が他の人の記事へ移ることもあります（推論）。どの記事の下に表示されるかは選べません。

  • ページビューへのつながり：間接

  • タイミング：公開するとき

  • ページビューへのつながり：間接
  • 根拠の種類：公式
  • 直接いえることか：推論を含む提案（公式が述べているのは参加の勧めと掲載先までで、選ばれなかった記事のページビューが増えるかは示されていません）。
  • 実行例：書こうとしている内容に合うお題を「投稿企画」で探し、公開設定でそのお題を選んで投稿する。
  • 条件と限界：内容が合わない企画に無理に参加しないでください。企画ごとに応募条件があります。選ばれて紹介された場合の増加は別の話です。主な経路は、お題のハッシュタグページです（選ばれた場合は編集部の紹介）。
  • 対応する公式出典：O7・O10・O17・O18

  • ページビューへのつながり：間接
  • 根拠の種類：公式
  • 直接いえることか：推論を含む提案（公式が述べているのは、知ってもらうこととフォローして読んでもらえることまでで、ほかの記事のページビューが増えるという説明はありません）。
  • 実行例：プロフィール欄に、何について書いているアカウントかを140文字以内で書く。
  • 条件と限界：効果が出るのは、クリエイターページまで来た読者に限られます。記事を固定表示する機能もありますが、効果の説明は確認できていません（T24）。

効果の確かめ方

  • 見る画面：ブラウザ版のダッシュボード「アクセス状況」、またはバージョン10.20.0以降のアプリの「アクセス状況」です。10.19.0以前のアプリは、これまでの「全体ビュー」の画面のままで、ページビューを分けて見られません。

ページビューが落ちたときの確認順

  1. 比べている数字が同じ指標・同じ期間かを確かめます（リニューアル前の「ビュー」や、古い版のアプリの「全体ビュー」と比べていないか）。
  2. 「インプレッション」が減ったのか、「インプレッション」は変わらず「ページビュー」だけ減ったのかを分けます。前者はnoteの中での表示が減った場合です。後者は、タイトルや見出し画像が合っていない場合のほか、検索やSNSなど外部からの流入が減った場合にも起こります（推論）。
  3. 「記事の流入元」で、どの流入元が減ったかを見ます。これは全記事をまとめた内訳で、記事ごとの流入元と、noteの中の内訳は、この画面では計測できません。
  4. 自分の側の変更（タイトル・見出し画像・ハッシュタグの変更、記事の削除や非公開）を振り返ります。
  5. noteの側の変更（2026年9月15日のキーワードページ、法人向けプランの追加表示など）がなかったかを、公式のお知らせで確かめます。

おすすめに載ったかどうか、検索での順位、同じ人が何回開いたか、本人の閲覧の回数は、書き手の画面では計測できません。

  • noteの中：見出し画像（C1）、タイトル（C2）、ハッシュタグ（C4）、記事の下のおすすめ設定（C5）、お題（C7）、マガジン（C10）が使えます。お題やハッシュタグに合うテーマの記事と、連載の続きに向きます。裏づけは、記事の下のおすすめ設定とマガジンが表示まで、ハッシュタグは知ってもらう機会までです。
