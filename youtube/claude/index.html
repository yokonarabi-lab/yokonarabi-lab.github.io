YouTube攻略法｜公開用の成果物

調査基準日：2026年11月21日（日本時間）

  • 対象：日本語圏に向けて発信する個人の公開チャンネルです。形式はShortsと通常動画を扱います。
  • 主指標：投稿1件あたりの公開の視聴回数です。広告による視聴を除いた、自然な視聴を増やすことを目的にします。自分のチャンネルでは、パソコンの YouTube アナリティクスにある［オーガニック トラフィックと有料のトラフィック］のフィルタで、広告以外からの視聴を切り分けられます。
  • 用語の対応：この資料の「Shorts」は公式の「YouTube ショート（ショート動画）」、「通常動画」は公式の「長尺動画（動画、VOD）」にあたります。経路の分類は、公式のアナリティクスでは「ホーム」と「登録チャンネル」が「ブラウジング機能」、「Shortsフィード」が「ショート フィード」（トラフィック ソースの一覧での見出しは「ショート動画」）、「検索」が「YouTube 検索」、「外部」が「外部ソース」にあたります（「関連動画」「チャンネル ページ」は同じ名前です）。
  • Shortsの条件：一般のチャンネルでは、2024年10月15日以降にアップロードされた、正方形または縦長で3分以内の動画です。それより前にアップロードされた動画は、従来の扱いのままです（公式アーティスト チャンネルなどでは、1分を超え3分以内の動画がShortsになるのは、2025年12月8日以降にアップロードされたものからです）。
  • 視聴回数の数え方：公式の説明では、Shortsは2025年3月31日から、通常動画を含むすべての形式は2026年8月24日から、再生が始まった時点で1回と数えます（最短の再生時間の条件はありません。Shortsはリプレイも数えます）。通常動画も、ホームなどで自動的に再生が始まれば、その時点で数えられます。サムネイルが表示されただけなら、視聴回数ではなくインプレッションです。2026年11月16日からは、テレビで一緒に見ている人数の推定（共視聴）も、公開の視聴回数と総再生時間に含まれます。自分の動画を広告に使った場合は、広告の視聴も公開の視聴回数に含まれることがあります。
  • 従来の数え方にあたる指標：「エンゲージ ビュー」です。クリックやタップで再生を始めた視聴と、自動的に始まった再生のうち最初の数秒を超えて見られた視聴を数えます。ループ再生と共視聴は含みません。何秒からかは公表されていません。YouTube アナリティクスに残っており、公式の告知では［詳細モード］で確認できると案内されています（告知の本文は作成者の環境では取得できず、検品者による本文の照合と報道での確認です）。
  • 指標：「平均視聴時間」は、視聴を続けた人の1回あたりの平均の視聴時間です。「平均視聴率」（英語名 Average percentage viewed）は、視聴を続けた人が動画全体の何割を見たかの平均です。どちらもエンゲージ ビューをもとに計算されます。「視聴者維持率」は、動画のどの時点まで視聴が続いたかの推移です。「サムネイルのインプレッションのクリック率」は、YouTube上でサムネイルが表示された回数のうち視聴された割合で、外部サイト・通知・終了画面などからの視聴は分母に入りません。
  • 比較の注意：2025年3月30日までと31日以降のShorts、2026年8月23日までと24日以降の通常動画、2026年11月15日までと16日以降の数字、形式の違う動画、公開からの日数が違う動画は、公開の視聴回数をそのまま比べられません。

第三者の分析や経験則も参照していますが、編集方針により出典詳細は非公開です。そのため、読者が直接検証できる範囲には制約があります。

結論

形式の優劣は判断できない、というのが結論です。最優先にする行動は、タイトルとサムネイル（Shortsは最初の画面）で示した内容を、冒頭ですぐ見せることです。公式は、おすすめが特定の形式を優先せず、表示されたときに選ばれるか、見続けられるか、満足されるかを見ていると説明しています。公開の視聴回数は、今はどちらの形式も再生開始から数えますが、フィードとホーム・検索では表示のされ方や視聴者層が違い、今の数え方で自然な視聴と観測期間をそろえた比較も確認できていません。そこで目的別に、新しい視聴者に知ってもらうならShorts、検索される題材や時間をかけて見てもらう内容なら通常動画を選びます。そろえた比較が出れば、この結論は変わりえます。

C1 冒頭で約束を果たす

  • 理由：公式は、おすすめが「表示されたときに選ばれるか」「見続けられるか」「満足されるか」を見ていると説明しています。Shortsでは、表示されたときに視聴を選んだ人の割合が順位の手がかりになるとされ、通常動画には冒頭30秒のあとも見続けた人の割合を示す指標が用意されています。タイトルやサムネイルから受ける期待と冒頭の内容が合っていることが、その割合を高める方法として公式に挙げられています。
  • 視聴回数へのつながり：間接
  • 根拠の種類：公式
  • 直接いえることか：推論を含む提案です。公式は指標と改善の方向を示していますが、視聴回数がどれだけ増えるかは示していません。
  • 実行例：タイトルが「〇〇の直し方」なら、あいさつや前置きより先に、直した結果か手順の全体像を見せる。
  • 条件と限界：主な経路の内訳は、ShortsがShortsフィード、通常動画がホームと関連動画です。何秒以内という一律の基準は公式にありません。
  • 対応する公式出典番号：O5、O7、O8、O26

C2 題名とサムネ改善

  • 理由：ホームや検索結果などでは、内容が分かるタイトルとサムネイルが、視聴者が動画を選ぶ手がかりになります。公式は、内容を正確に表して興味を引くタイトルとサムネイルを勧め、誤解を招く表現を避けるよう説明しています。
  • 視聴回数へのつながり：両方
  • 根拠の種類：公式
  • 直接いえることか：推論を含む提案です。
  • 実行例：動画の中で実際に見せる場面をサムネイルに使い、タイトルは「何が・どうなるか」が一目で分かる言葉にする。
  • 条件と限界：主な経路の内訳は、ホーム、関連動画、検索など、サムネイルが表示される場所です。クリック率が高くても表示が増えるとは限らず、クリック率は表示先が広がると下がるのが普通だと公式は説明しています。クリックを集めても平均視聴時間が短い動画は、おすすめされる可能性が低くなるとも説明されています。Shortsは主にフィードで自動的に再生されるため、対象を通常動画にしました。
  • 対応する公式出典番号：O6、O8、O10、O12、O17、O31

C3 視聴者を一つ決める

  • 理由：公式は、おすすめが視聴者ごとに作られ、その人があるチャンネルや題材の動画をどれだけ見てきたかを手がかりにすると説明しています。似た題材や見慣れた形式で一貫した内容を出すチャンネルには視聴者が戻ってくる傾向があり、あるチャンネルをよく見る人にはそのチャンネルの動画がおすすめされやすくなるとも説明されています。
  • 視聴回数へのつながり：間接
  • 根拠の種類：公式
  • 直接いえることか：推論を含む提案です。
  • 実行例：投稿の前に「この動画は誰が、どんなときに見るか」を1行で書き、直近の動画と同じ人が見たくなる内容かを確かめてから公開する。
  • 条件と限界：テーマを一つに絞ること自体が優遇されるわけではありません。経路ごとの効果を示す資料がないため、主な経路は「特定不可」です。視聴者がはっきり違う内容は別のチャンネルに分けることも選択肢だ、という公式の責任者の発言があります（報道経由の確認で、参考です）。
  • 対応する公式出典番号：O9、O11、O20、O30（参考：O23）

C4 検索語を題名に

  • 理由：公式は、検索の順位が、タイトル・説明・動画の内容が検索語に合う度合いと、その検索での視聴者の反応で決まると説明しています。Shortsの検索でも、検索語との一致と、クリックされて視聴されるかが手がかりになるとされています。調べものや手順のように検索される題材では、探す人が使う言葉をタイトルと説明欄に入れることが直接の対策になります。
  • 視聴回数へのつながり：直接
  • 根拠の種類：公式
  • 直接いえることか：検索での関連性については直接いえます。順位や視聴回数の保証はありません。
  • 実行例：視聴者が打ちそうな言い方（例：「確定申告 やり方 初めて」）をタイトルの前半に入れ、説明欄の最初の文でも同じ言葉で内容を説明する。
  • 条件と限界：検索される題材に向いた施策です。実際には出てこない内容を見られると思わせるような、誤解を招く書き方はポリシー違反です。
  • 対応する公式出典番号：O8、O13、O17、O26、O29

C5 尺を水増ししない

  • 理由：公式は、理想の長さは一律に決まらず、価値を届けるのに必要な長さにして引き延ばしを避けるよう説明しています。短い動画では見られた割合、長い動画では見られた時間の量がより重く見られるため、不要な部分は割合を下げるだけになります。
  • 視聴回数へのつながり：間接
  • 根拠の種類：公式
  • 直接いえることか：推論を含む提案です。
  • 実行例：公開後に視聴者維持率のグラフで大きく下がっている箇所を確かめ、次の動画ではその種類の場面（長い前置きなど）を削る。
  • 条件と限界：8分以上は動画の途中に広告を入れられる条件で、おすすめの優遇ではありません。短ければよいという意味でもありません。主な経路は「特定不可」です。
  • 対応する公式出典番号：O7、O8、O10、O19

C6 題名サムネをテスト

  • 理由：公式の機能で、1本の動画に最大3つのタイトルとサムネイルを設定し、視聴者に出し分けて比べられます。判定は総再生時間の割合で行われるため、クリックだけを集めて離脱される案は選ばれにくい仕組みです。
  • 視聴回数へのつながり：間接
  • 根拠の種類：公式
  • 直接いえることか：機能の仕組みは直接いえます。視聴回数が増えるという部分は推論を含む提案です。
  • 実行例：サムネイルだけを変えた2〜3案（文字あり・なしなど）を登録し、結果が出るまでほかの変更をしない。
  • 条件と限界：パソコンのYouTube Studio だけで使え、上級者向け機能を有効にする必要があります。Shortsのほか、子ども向け・成人向け・非公開の動画は対象外です。テストは2週間以内に終わるとされ、差が出ない結果もあります。主な経路の内訳は、サムネイルが表示されるホーム、関連動画、検索などです。
  • 対応する公式出典番号：O16

C7 不調動画を手直し

  • 理由：公式は、タイトルやサムネイルを変えると視聴回数が上がることも下がることもあり、それは変更後の視聴者の反応によると説明しています。変更を勧める目安として挙げられているのは、クリック率が低く、表示回数もふだんより少ない場合です。
  • 視聴回数へのつながり：両方
  • 根拠の種類：公式
  • 直接いえることか：変更を検討する目安は直接いえます。改善の保証はありません。
  • 実行例：ふだんの動画よりクリック率と表示回数の両方が低い動画を1本選び、サムネイルだけを内容がより伝わるものに替える。
  • 条件と限界：調子のよい動画は変えません。替えても伸びない場合、その題材に関心のある人が少ない可能性があると公式は説明しています。主な経路の内訳はC6と同じです。
  • 対応する公式出典番号：O8、O10、O12

C8 次の動画へ案内

  • 理由：公式は、シリーズ化、次の動画の呼びかけ、再生リスト、終了画面を、視聴者が次の動画を見つける助けとして挙げています。1本を見た人が同じチャンネルの別の動画を見れば、その動画の視聴が直接増えます。
  • 視聴回数へのつながり：直接
  • 根拠の種類：公式
  • 直接いえることか：推論を含む提案です。
  • 実行例：動画の最後に、続きにあたる1本を言葉で紹介し、同じ動画を終了画面に設定する。
  • 条件と限界：増えるのは案内した先の動画の視聴です。主な経路の内訳は、終了画面、再生リスト、関連動画です（比較用の分類では「その他：終了画面」「その他：再生リスト」にあたります）。効果の大きさを示す資料はありません。
  • 対応する公式出典番号：O9

C9 続けられる頻度

  • 理由：公式は、投稿の間隔と視聴回数の伸びに相関は見られないとして、頻度より質を保つことを勧めています。Shortsにも、成績を上げるために必要な最低の投稿頻度はないとされています。響かない動画を頻繁に出し続けると、チャンネル全体の成績に影響しうるとも説明しています。
  • 視聴回数へのつながり：間接
  • 根拠の種類：公式
  • 直接いえることか：頻度を上げても1本あたりが増えるとはいえない、という点は直接いえます。質を保つことで増える量は示されていません。
  • 実行例：1本にかける準備の時間を先に決め、それを守れる投稿の間隔にする。
  • 条件と限界：投稿の本数が増えれば、チャンネル合計の視聴は増えることがあります。合計と1本あたりは分けて考えます。休んでも罰はないと公式は説明しています。主な経路は「特定不可」です。
  • 対応する公式出典番号：O8、O9、O26

C10 Shortsから案内

  • 理由：公式の機能で、Shortsに自分の動画・別のShorts・ライブ配信へのリンク（関連動画）を付けられます。公式は、Shortsだけを見る人もいれば、Shortsで見つけてから長い動画に進む人もいると説明し、Shorts単体で内容を完結させたうえで、見た人の目的に合う動画へつなぐことを勧めています。
  • 視聴回数へのつながり：直接
  • 根拠の種類：公式
  • 直接いえることか：機能と助言は直接いえます。どれだけの人が移るかは示されていません。
  • 実行例：手順の一部だけを見せるShortsに、全体を説明する自分の通常動画を［関連動画］として設定する。
  • 条件と限界：上級者向け機能を使えることが条件で、リンク先は公開または限定公開の動画です。増えるのは案内した先の動画の視聴で、リンク元のShortsやリンク先のおすすめが増える効果は確認できていません。主な経路は、比較用の分類では「その他：Shortsの関連動画リンク」です。
  • 対応する公式出典番号：O32、O33

補足

  • 効果の確かめ方：同じ形式どうしを、公開からの日数をそろえて比べます（たとえば、どの動画も公開から28日後の数字で比べる）。パソコンのアナリティクスの［オーガニック トラフィックと有料のトラフィック］で自然な視聴回数を確かめ、公開の視聴回数の合計、エンゲージ ビュー、総再生時間はそれぞれ別に見ます。計測方式が変わった日をまたぐ比較はしません。2026年11月16日の変更後に公開した動画だけで7日分・28日分の数字がそろうのは、基準日より後です。
  • 再生数が落ちたときの確認順：まず、比べている期間が計測方式の変更日をまたいでいないかを確かめます。そのうえで、公式が挙げる順に、(1) 自分が最近変えたこと（題材、編集、サムネイル、頻度、長さ）、(2) 題材への関心の変化、(3) どの視聴者層が減ったか（新しい視聴者・ライトな視聴者・コアな視聴者）、(4) 季節による変動、を確認します。
  • 両形式の使い分け：Shortsのフィードは新しさと流行を重視し、新しい視聴者に見つけてもらう場になります。通常動画は、検索される題材や、時間をかけて見てもらう内容に向きます。同じ人が両方を見るとは限らないため、形式ごとに1本で完結する内容にします。
  • 他媒体へ応用できる考え方：冒頭で約束を果たす、誰に向けた動画かを決める、水増ししない、他人の動画をそのまま転載しない、という考え方は媒体を問わず使えます。
