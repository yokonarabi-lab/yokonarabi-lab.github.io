X攻略法｜公開用の成果物

調査基準日：2026年10月23日（日本時間）

対象：日本語で発信する個人の公開アカウント。目的は「1投稿あたりのインプレッション（投稿アナリティクスの表示回数）」を伸ばすこと。

インプレッションの定義：公式ヘルプでは「タイムラインや検索結果で投稿が利用者に表示された回数」です（S1）。公開の「表示回数」は「ログイン中の利用者が投稿を見た合計回数」で、公式に両者の違いを説明した記述は確認できませんでした（S2）。アカウント全体のアナリティクスは2024年6月以降、有料プラン向けに案内されていますが、投稿ごとのアナリティクスの利用条件を説明する現行のヘルプページは基準日時点で取得できませんでした。

第三者の分析や経験則も参照していますが、編集方針により出典詳細は非公開です。そのため、読者が直接検証できる範囲には制約があります。

結論

公開コードでは、おすすめ欄は「予測した反応の確率に重みを掛けて足す」仕組みで、返信・引用・共有の重みがいいねより大きく、滞在時間も予測の対象です。まず効くのは、投稿単体で反応が生まれ、最後まで読まれる内容です。外部リンクは公式が「減点していない」と繰り返しており、本文に説明を付ければ使えます。短時間の連投は1投稿あたりでは不利になりうるので控えめにし、交流のある相互フォローを増やし、有料プランは返信の優先表示を期待して検討する、という順番をおすすめします。

1位C1反応が生まれる内容

  • 理由：公開コードでは、返信・引用・DMでの共有・リンクコピーでの共有・投稿者のフォローの予測確率に、いいねより大きな重みが掛かっています（2026年10月22日同期の設定値で、返信5.0、引用5.0、リンクコピー共有20.0、フォロー4.0、いいね0.66）。この重みは予測確率に掛かるもので「返信1件はいいね何件分」とは読めませんが、順位づけが「人に反応させる投稿」を優先する方向にあることは確認できます。2026年10月20日には、オーナーが滞在時間の予測を強めた順位モデルと「最後まで読まれる投稿」を取る検索モデルへの変更も説明しています。
  • 閲覧数へのつながり：直接。おすすめ欄での順位づけの仕組みは公式コードと経営陣の説明で確認できますが、実際のインプレッション増加を測ったデータは確認していません。
  • 根拠の種類：公式。
  • 判断の位置づけ：推論を含む提案（順位づけの仕組みから、反応が生まれ最後まで読まれる内容が有利と推論）。
  • 条件や限界：「返信して」「フォローします」と反応を乞う形は、順位を下げる方針が経営陣から示されており、逆効果になりえます。設定値は約4週間ごとに更新されるため、数値は変わります。
  • 対応する公式出典：S7、S31、S94。

2位C2リンクは説明つき

  • 理由：2025年10月から2026年7月にかけて、オーナーとプロダクト責任者が「リンクは減点していない」「本文にリンクを置き、クリック前に何が見えるか十分な文脈を書く」「説明がほとんどないリンク投稿は配信が弱い」と繰り返し説明しています。公開コードにはリンクによる除外や固定の減点係数は確認できず、リンクの有無は特徴量としてモデルの学習に使われるため、学習された影響の向きは公開情報からは分かりません。
  • 閲覧数へのつながり：両方。公式はリンク自体の減点を否定していますが、第三者のデータでは「リンク入りの投稿は反応・表示が低い」という相関が複数の独立した集計で一致しています。説明のないリンク投稿は、公式も配信が弱いと認めています。
  • 根拠の種類：公式、データ分析。
  • 判断の位置づけ：推論を含む提案（「リンクだけの投稿を避け、説明を書く」は公式の推奨。リンク入り投稿が平均的に伸びにくい傾向は第三者データの相関で、因果は未確認）。
  • 条件や限界：リンク入り投稿がリンクなし投稿と同じだけ伸びるとは言えません。閲覧数が最優先ならリンクのない投稿のほうが無難で、リンクが必要なときに本文の説明を厚くする、という使い分けです。リンクを返信に置くほうがよいかは、直接比較したデータがありません。
  • 対応する公式出典：S7、S9、S24、S25、S26、S27、S28。

3位C3有料プランの検討

  • 理由：公式ヘルプが説明する有料プランの効果は「返信の上位表示（ベーシック）」「さらに上位（プレミアム）」「返信のブースト・3プラン中最大（プレミアムプラス）」で、対象は返信欄の順位です。第三者の大規模集計では、有料プラン加入アカウントの1投稿あたりの表示回数の中央値が未加入より大きく高い傾向が見られますが、旧プラン時代の横断比較で、同じアカウントの加入前後を比べたものではありません。
  • 閲覧数へのつながり：両方。返信欄での上位表示は公式が説明しています。おすすめ欄や通常投稿のインプレッション増加は、第三者の相関データのみで、2026年版の公開コードには有料・認証による加点の係数は見当たりません。
  • 根拠の種類：公式、データ分析。
  • 判断の位置づけ：推論を含む提案。
  • 条件や限界：有料：新規に加入する場合は「The X Subscription」（Plus／Premium／Super／Ultra。2026年10月12日発表、世界へ順次展開）、すでに加入している場合は旧「X Premium」（ベーシック／プレミアム／プレミアムプラス）を維持できます。新しい Premium 以上には旧プレミアムプラス相当の X の特典が含まれ、同じ「Premium」でも新旧で別のプランです。日本語ヘルプは基準日時点で旧プランのみを記載しているため、日本で新規に選べるプラン名と円建て価格は購入画面で確認してください。第三者の表示回数データは旧プラン時代のもので、新プランの効果として読まないでください。返信の優先表示は「返信投稿」の順位の話で、通常投稿のおすすめ掲載を約束するものではありません。
  • 対応する公式出典：S3、S4、S5、S7。

4位C4連投を避ける

  • 理由：公開コードでは、おすすめ欄を組み立てるとき、同じ画面の候補に同じ投稿者の投稿が複数あると2本目以降のスコアが減衰します（2本目0.625倍、3本目約0.44倍、下限0.25倍）。候補は投稿後48時間まで残るため、同じ日に出した複数の投稿は同じ閲覧者の画面で競合しえます。第三者のデータでも、投稿数を増やすと合計の反応は増えても1投稿あたりの反応は下がる傾向が複数の集計で見られます。
  • 閲覧数へのつながり：直接。減衰の仕組みは公式コードで確認できます。1投稿あたりの反応の低下は第三者の相関データで、1投稿あたりのインプレッションを直接比べたデータは確認していません。
  • 根拠の種類：公式、データ分析。
  • 判断の位置づけ：推論を含む提案（仕組みから「同じ画面で自分の投稿同士が競合する」ことは言えますが、「間隔を空ければ伸びる」「1日何本までなら安全」という効果量は確認できていません）。
  • 条件や限界：1日の合計インプレッションを増やしたい場合は投稿数を増やす効果があります。ここでの目的は1投稿あたりなので、分けて考えてください。減衰は「同じ画面に並ぶ候補」の中での話です。
  • 対応する公式出典：S7。

5位C5投稿後の返信対応

  • 理由：公開コードでは、投稿から48時間を過ぎた投稿は候補から外れ、フォロワー5万人以下の投稿者の投稿は「投稿後2時間以内かつ表示200回未満」のあいだ順位を引き上げる枠があります。第三者のデータでは、投稿へのインプレッションは投稿直後に集中し、自分の投稿についた返信に返すと反応がわずかに増える傾向があります。
  • 閲覧数へのつながり：間接。初動で会話が生まれると返信数が増え、返信の予測確率に掛かる重みを通じて順位に効くという経路は推論です。
  • 根拠の種類：公式、データ分析。
  • 判断の位置づけ：推論を含む提案。
  • 条件や限界：会話に返すのと、件数を増やすために中身のない返信を重ねるのは別です。大量・重複の返信は公式ルールでスパムの例に挙げられています。
  • 対応する公式出典：S7、S8。

6位C6相互の関係づくり

  • 理由：2026年7月にプロダクト責任者が「相互フォローの相手への投稿の表示を上げる小さな調整」を実施したと説明し、公開コードにも相互フォローの投稿者の通常投稿について返信の重みを大きく加算する設定（+15.0）があります。実際に交流のある相手が増えれば、その相手のおすすめ欄で自分の投稿が上位になりやすくなります。
  • 閲覧数へのつながり：直接。相互フォローの相手の画面での順位の上昇は公式コードと経営陣の説明で確認できますが、全体のインプレッションがどれだけ増えるかのデータはありません。
  • 根拠の種類：公式。
  • 判断の位置づけ：根拠から直接いえる（相互フォロー相手の画面での優遇）。全体への効果は推論を含む提案です。
  • 条件や限界：効果は相互フォローの相手の画面に限られ、全体での大きさは未確認です。数値目的の相互フォロー募集・フォロー返し企画は、公式ルールで「相互交換」として制限の対象になり、逆効果です。
  • 対応する公式出典：S7、S33、S8、S9。

7位C7時間帯の確認

  • 理由：第三者の大規模な集計では、平日の日中（投稿者の現地時間）に反応が多く、土曜が最も低いという傾向が複数のデータで一致しています。ただし指標は反応数で、日本語圏の読者に向けた日本時間の独立したデータは確認できませんでした。
  • 閲覧数へのつながり：間接。読者が見ている時間に出せば初動の反応が増えやすい、という経路です。
  • 根拠の種類：データ分析。
  • 判断の位置づけ：推論を含む提案。
  • 条件や限界：公式ヘルプにも公開コードにも、時間帯による加点はありません。自分の投稿アナリティクスで確認して合わせるのが前提です。海外のデータの時間帯をそのまま日本時間に当てはめないでください。
  • 対応する公式出典：直接の公式出典なし。

8位C8コミュニティ投稿

  • 理由：公式ヘルプでは、コミュニティ内の投稿はコミュニティのページだけでなく、メンバーのホームタイムライン、投稿者のフォロワー、プロフィール、検索にも通常の投稿と同じように表示されると説明されています。つまり同じ関心を持つ人の画面に、フォローされていなくても届く経路が増えます。
  • 閲覧数へのつながり：間接。表示先が増えることは公式が説明していますが、インプレッションがどれだけ増えるかのデータはありません。
  • 根拠の種類：公式。
  • 判断の位置づけ：推論を含む提案。
  • 条件や限界：参加には公開アカウントが必要です。コミュニティの投稿には表示回数が表示されないと公式ヘルプにあり、効果を自分で測りにくい点に注意してください。
  • 対応する公式出典：S18、S2。

9位C9自作メディア

  • 理由：公開コードの設定値では、画像の拡大や動画の再生の予測に掛かる重みは小さく（画像拡大0.05、動画を開く0.02）、画像や動画を付けるだけで有利になる固定の仕組みは確認できません。一方で、他媒体の透かし入り動画の転載はインプレッションが大きく減ると経営陣が説明しており、公式のベストプラクティスも文字の多い画像を避けるよう勧めています。
  • 閲覧数へのつながり：両方。転載動画の減少は経営陣の説明、文字だらけの画像の回避は公式の推奨です。自作メディアが伸びるというデータは確認していません。
  • 根拠の種類：公式。
  • 判断の位置づけ：推論を含む提案。
  • 条件や限界：第三者のデータでは、文字だけの投稿のほうが画像・動画付きより反応率が高い集計もあり、形式そのものより内容が結果を左右します。
  • 対応する公式出典：S7、S34、S17。

10位C10フォローされる状態

  • 理由：公開コードでは「投稿者をフォローする」予測確率に大きめの重み（4.0）があり、フォローされやすい投稿が順位で有利です。またフォロワーの画面に出るフォロー中の候補は、おすすめ欄の候補の主要な供給源の一つです。
  • 閲覧数へのつながり：両方。順位への効きは公式コードで確認できます。フォロワーが増えると1投稿あたりのインプレッションがどれだけ増えるかのデータはありません。
  • 根拠の種類：公式。
  • 判断の位置づけ：推論を含む提案。
  • 条件や限界：プロフィールのクリックの重みは0.0で、プロフィールを見られること自体は加点になりません。フォローしたくなるのは投稿の内容とテーマの一貫性なので、C1 と組み合わせて考えてください。
  • 対応する公式出典：S7。

やらないこと

公式に根拠を確認できた、閲覧数の低下やおすすめへの掲載制限につながる行動です。ルール違反による制限と、仕組み上の不利益は区別して書きました。公式が「可能性」として説明するものは、必ず起こる結果ではありません。

  • N1
    • やらないこと：いいね・リポスト・フォローを互いに付け合う企画（いいね回し、相互フォロー募集、フォロー返し）に参加しません。
    • 理由：公式ルール（信頼性、プラットフォームの操作およびスパム）が「反応の交換」「フォロートレイン」を明確に禁止し、検索・トレンド・おすすめからの除外やタイムラインからの削除などの制限を「取りうる措置」として説明しています。オーナーも2024年4月にエンゲージメント・ファーミングのアカウントは凍結すると警告しています。
    • 根拠の種類：公式。
    • 対応する公式出典：S8、S9、S30。
  • N2
    • やらないこと：同じ内容の投稿を繰り返したり、投稿と削除を繰り返したりしません。
    • 理由：公式ルールが「同一・酷似した内容の繰り返し投稿」「投稿と削除の繰り返し」をスパム行為の例に挙げ、表示の制限や機能制限の対象としています。
    • 根拠の種類：公式。
    • 対応する公式出典：S8、S9。
  • N3
    • やらないこと：説明のない「リンクだけ」の投稿を繰り返しません。
    • 理由：公式ルールは「説明のないリンクだけの投稿」をスパムの例に挙げ、経営陣も説明がほとんどないリンク投稿は配信が弱いと説明しています（コメントなしで時々リンクを投稿すること自体は違反ではありません）。
    • 根拠の種類：公式。
    • 対応する公式出典：S9、S8、S24。
  • N4
    • やらないこと：他の媒体から転載した動画（透かし入りなど）を投稿しません。
    • 理由：プロダクト責任者が2026年4月に、他SNSからの転載動画はインプレッションを大幅に減らすと説明しています。
    • 根拠の種類：公式。
    • 対応する公式出典：S34。
  • N5
    • やらないこと：内容と無関係なハッシュタグやトレンドのハッシュタグを大量に付けません。
    • 理由：公式ルールが無関係・過剰なハッシュタグやトレンドの乱用をスパムの例に挙げています。公式ヘルプの推奨は1投稿2個までです。
    • 根拠の種類：公式。
    • 対応する公式出典：S9、S16。

判定（5つのうち1つ）

  • 本当：公式情報または第三者の独立した検証・データが、説の中心的な主張をそのまま裏づけている。
  • 半分本当：根拠で確認できる条件を足した場合に限って成り立つ。条件と、一般化できない範囲を理由に書く。
  • 言いすぎ：方向性を支持する根拠はあるが、必須性・強さ・範囲・決定性を過大に述べている。どこまで弱めれば支持できるかを書く。
  • 嘘：中心的な主張に反する十分な根拠がある。公式が触れていない、コードにないという理由だけでは選ばない。
  • 根拠なし：支持・反証のどちらにも判定に足る根拠を確認できない、情報にアクセスできない、または根拠が対立して決められない。

補足：「本当」は全員への成果保証ではありません。「半分本当」は確率50％という意味ではなく、「嘘」は発信者の意図的な虚偽を意味しません。「根拠なし」は判定に足る根拠を確認できないという意味で、根拠そのものが存在しないと断定する言葉ではありません。この5分類は、強い・弱いの一本の数値尺度ではありません。

根拠（4つのうち1つ）

  • 公式：公式情報が主張を直接裏づけ（または反証）している。
  • 第三者：公式は関連する仕組みの説明のみか触れておらず、直接の裏づけ（または反証）は第三者の独立した検証・データ。
  • 公式＋第三者：両方がある。
  • なし：判定に足る根拠がない、または根拠が対立して決められない（判定が「根拠なし」のとき）。

扱いは行動に付けます：やる／条件つきで試す／後回し／やらない。
「伸びる」は特記がなければ「1投稿あたりのインプレッションが増える」ことです。T12〜T14 はおすすめ欄の順位づけについて、T20〜T22 は「操作した本人以外への表示も減る」かについて判定しています。
重みの数値は、2026年10月22日に同期された公開コードの設定値で、予測確率に掛かる係数です。「反応1件につき何点」ではありません。公開コードに「ない」ことは、固定の係数が確認できないという意味で、学習された影響がないという意味ではありません。
