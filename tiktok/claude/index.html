TikTok攻略法｜公開用の成果物

基準日：2026年11月8日（日本時間）

対象：日本語圏の視聴者に向けて発信する個人の公開アカウントが、広告を使わずに投稿する通常の動画と写真投稿（複数枚のスライドを含む）。目的は、TikTok内での投稿1件あたりの再生数を伸ばすことです。LIVE、Stories、TikTok Shop、広告、収益化は扱いません。

指標の定義

  • この資料の「再生数」は、投稿1件ごとに表示される視聴の回数のことです。公式の日本語ヘルプは「視聴数」「動画視聴数」という語を使っています（S1）。英語のクリエイター向け解説は、私が取得できた本文では、分析画面（Analytics）の全体表示を「Video views」、投稿ごとの表示を「Total views」と書いています（S9）。相互検品の相手側は、同じページで別の表記を確認したと報告しており、取得結果に差があります。日本語の分析画面での正式名称も、公式ページでは確認できていません。実際の表記は、アプリの画面で確かめてください。
  • 何秒見たら1回になるのか、同じ人が繰り返し見た分、投稿者自身が見た分、写真投稿でスライドを送った分、TikTok Liteで見られた分が数に入るのかは、公式情報で確認できず、不明です。動画と写真投稿で数え方が同じかどうかも不明です。そのため、再生数は「見た人の数」とは別のものとして扱います。
  • 分析画面には、平均視聴時間（Average watch time）と、最後まで見た人の割合（Watched full video）が、再生数とは別の指標としてあります（S9。私が取得できた本文の説明です）。写真投稿で見られる指標が動画と同じかどうかは確認できていません。
  • 写真投稿は、複数の静止画を1件の投稿として出す形式で、公式発表時の名称は「Photo Mode」です（S12）。1件あたりの枚数の上限は、開発者向けの公式資料では35枚です（S14）。
  • 動画の長さの上限は、公式の日本語ヘルプでは、アプリ内で撮影する場合が最大60秒、アップロードする場合が最大3分と書かれています（S6）。英語版ヘルプはこれより長い上限を案内しているとされますが、原文を確認できませんでした。日本の個人アカウントで実際に選べる上限は、アプリの画面で確かめてください。

第三者の分析や経験則も参照していますが、編集方針により出典詳細は非公開です。そのため、読者が直接検証できる範囲には制約があります。

結論

動画優先を勧めます。再生数で比べた第三者の集計では、同じ発信者の投稿どうしでも動画のほうが写真投稿より多い傾向で、写真投稿のほうが多いとする比較可能な根拠は確認できませんでした。ただし、これは観測された傾向です。同じ題材を形式だけ変えて比べた結果ではなく、写真投稿の再生数の数え方も公式に確認できていません。動画を軸にするのは、この傾向に加えて、冒頭や尺など公式の説明をたどれる改善策が動画に多いためです（推論を含む提案）。写真投稿は、手順・比較・一覧のように自分の速さで読ませたい題材で選んでください。同じ題材を両方の形式で出す必要はありません。自分の似た投稿同士で写真投稿のほうが多い状態が続くなら、写真の比率を上げてください。

実践チェックリスト

以下は、実測の効果順位ではなく、調査に基づく推奨順位です。順位は、投稿1件あたりの再生数への期待効果が大きいと判断した順で、手間や費用は順位に入れていません。

採用の基準は次の3段階です。公式がおすすめや検索の仕組みとして説明している要素に直接はたらきかける行動を上位に、第三者の大規模な集計で方向が支持される行動を次に、経験則と推論だけにもとづく行動を下位に置きました。公式情報であることだけを採用の条件にはしていません。

勧められる施策は8項目にとどめました。流行の音源、投稿する時間帯、カバー画像、ループ構成、アプリ内での編集、投稿の本数を増やすことは、1件あたりの再生数について勧められるだけの根拠を確認できなかったため、順位に入れていません（扱いは「通説の判定」を参照）。

C1 冒頭の作り

  • 理由：公式は、視聴時間がおすすめの要素であることを挙げたうえで、冒頭で関心を引き、最後まで関心を保つ作りを勧めています（S40）。スキップも、おすすめに使われる「ユーザーのリアクション」の一つです（S1）。冒頭で内容が伝わらないと、見続けるかどうかを決める材料がないまま次の投稿へ送られます。
  • 再生数へのつながり：間接。確認されているのは、視聴時間やスキップがおすすめの順位づけに使われることと、公式が冒頭の作りを勧めていることです（公式）。冒頭を変えると再生数がどれだけ増えるかは確認されておらず、ここは推論です。
  • 根拠の種類：公式／個人の経験則
  • 判断の位置づけ：推論を含む提案。「3秒で決まる」という決定的な境目は確認できていません（T3）。視聴時間がいいねより重いかどうかも確認できていません（T12）。
  • 実行例：料理の動画で、材料を並べる場面から始めていたものを、完成した皿のアップと「レンジだけで作れます」の一言から始める形に変える（提案であり、成果が確認された例ではありません）。
  • 条件や限界：動画向け。S40は2020年の案内です。写真投稿に同じ仕組みが当てはまるかは、公式に確認できていません。撮り直しや編集の手間がかかります。
  • 対応する公式出典：S1、S40

C2 尺と間の整理

  • 理由：再生数を長さ別に集計した第三者の複数の資料で、短い動画ほど再生数が多いという関係は見られず、同じ発信者の中で比べても長い動画のほうが多い傾向でした（T1）。一方で、同じ企画を長くすれば伸びるという確認はなく、1分を境に急に増えるわけでもありません（T2）。そこで、長さを先に決めず、内容に必要な長さにして不要な部分を削るのが妥当だと判断しました。
  • 再生数へのつながり：間接。視聴時間がおすすめの要素であること（公式）と、長さ別の集計（データ分析。相関であって因果ではない）からの推論です。
  • 根拠の種類：公式／データ分析
  • 判断の位置づけ：推論を含む提案。最適な秒数は示せません。
  • 実行例：話す動画で、同じ説明の言い直しと最後の長いあいさつを切り、説明が終わった時点で動画も終える（提案であり、成果が確認された例ではありません）。
  • 条件や限界：動画向け。最後まで見た人の割合だけを見て短くしたり、合計の視聴時間だけを見て長くしたりしないでください。1分以上を条件にする収益化プログラムは、通常の配信での優遇を意味しません。使える長さの上限は、冒頭の定義のとおり公式の記載が分かれています。
  • 対応する公式出典：S1、S40

C3 題材選び

  • 理由：公式は、TikTokで検索されている内容を調べられる機能「Creator Search Insights」を日本でも提供し、よく検索されるのに取り上げた動画が少ない内容を探せると案内しています（S7）。検索では、入力された言葉とコンテンツの関連度が重視されます（S1）。
  • 再生数へのつながり：間接。機能があることと検索の仕組みは公式です。検索されている題材を選ぶと再生数が増える、という実測は確認できておらず、推論です。
  • 根拠の種類：公式／個人の経験則
  • 判断の位置づけ：推論を含む提案
  • 実行例：（動画の例）アプリの検索欄に「Creator Search Insights」と入れて機能を開き、自分の分野の検索語から、まだ扱っていないものを1つ選んで撮る（提案であり、成果が確認された例ではありません）。
  • 条件や限界：経路の内訳は、検索とおすすめです。検索の説明（S1）は「コンテンツ」について書かれていて形式を限っていませんが、機能の案内（S7）は動画を前提にしています。写真投稿が検索結果にどう表示されるかの公式説明は確認できておらず、写真投稿については推論の度合いが大きくなります。機能の利用条件と、いまのアプリでの場所は、画面で確認が必要です。費用はかかりません。
  • 対応する公式出典：S1、S7

C4 説明文とタグ

  • 理由：検索では入力された言葉とコンテンツの関連度が重視され、ハッシュタグはおすすめの「コンテンツの情報」に挙げられています（S1）。公式は、内容に関連するハッシュタグや説明を添えることを勧めています（S40）。説明文は、動画にも写真投稿にも付けられます（S12）。
  • 再生数へのつながり：間接。確認されているのは仕組みと公式の勧めです（公式）。第三者の集計では、説明文のない投稿やハッシュタグのない投稿は、同じ発信者のそうでない投稿より再生数が少ない傾向でした（データ分析。観測であり、言葉の選び方の効果を測ったものではありません）。検索されそうな言葉を足した効果や、タグを増やした効果の検証は確認できていません（T9、T10）。
  • 根拠の種類：公式／データ分析
  • 判断の位置づけ：推論を含む提案
  • 実行例：（写真投稿の例）説明文が絵文字だけだった収納の投稿に、「賃貸のクローゼット収納を100円の箱でそろえた手順です」と書き、「#収納」「#クローゼット収納」を付ける（提案であり、成果が確認された例ではありません）。
  • 条件や限界：経路の内訳は、検索とおすすめです。1投稿あたりのハッシュタグの個数と、説明文の文字数のいまの上限は、公式ヘルプで確認できていません（2022年10月の公式発表では、説明文は2,200文字まで。S12）。タグの数を増やすほど伸びるという根拠はありません。第三者の集計は、動画と写真投稿を分けていません。
  • 対応する公式出典：S1、S12、S40

C5 コメント返信動画

  • 理由：第三者の大規模な集計で、コメントへの返信として投稿された動画は、同じ発信者のほかの動画より再生数が多い傾向でした（観測）。コメントで質問が出た題材は、見る人が実際に知りたいと分かっている題材でもあります。通常のコメント返信で元の投稿の再生数が増えるという検証は、確認できていません（T23）。
  • 再生数へのつながり：直接（返信として出す動画そのものの再生数）。確認されたのは返信動画の再生数が多い傾向で（データ分析）、返信という形の効果なのか、関心の高い題材が選ばれた結果なのかは分かれていません。
  • 根拠の種類：データ分析／個人の経験則
  • 判断の位置づけ：推論を含む提案
  • 実行例：「その道具はどこで買えますか」というコメントに、コメントへの返信として動画を作り、道具の選び方を答える（提案であり、成果が確認された例ではありません）。
  • 条件や限界：動画向け。コメントに動画で返信する機能の、日本語の正式名称と利用条件は、公式ページで確認できていません。返信動画の再生は、元の投稿とは別の投稿の再生です。見返りや交換でコメントを集めるやり方はしないでください（N2）。集計は海外を含む発信者が対象で、返信動画かどうかは説明文の表記から判定されています。
  • 対応する公式出典：直接の公式出典なし

C6 音声と文字

  • 理由：内容が聞き取れない、読み取れない動画は、見続ける理由が伝わりません。字幕やテロップで再生数が増えたことを同じ条件で比べた検証は確認できませんでした（T5）が、理解しやすくする施策として、視聴時間がおすすめの要素であること（S40）と方向が合います。
  • 再生数へのつながり：間接。再生数への効果は推論です。
  • 根拠の種類：個人の経験則
  • 判断の位置づけ：推論を含む提案
  • 実行例：屋外で撮る動画で、スマートフォンのマイクを口元に近づけて録り直し、場面ごとの要点を1行のテロップで入れる（提案であり、成果が確認された例ではありません）。
  • 条件や限界：動画向け。写真投稿では画像の上の文字がこれに当たりますが、効果は確認できていません。話した言葉を文字にする字幕と、要点を足すテロップは別のもので、どちらが効くかの比較も確認できていません。編集の手間がかかります。
  • 対応する公式出典：直接の公式出典なし

C7 1枚目と順序

  • 理由：写真投稿は、複数の静止画が順に表示され、見る人が自分の速さで送れる形式です（S12）。1枚目で内容が分からなければ先を見る理由が伝わらない、という動画の冒頭と同じ考え方を当てはめた提案です。写真投稿の順位づけについての公式説明は、確認できていません。
  • 再生数へのつながり：間接。写真投稿の再生数への効果を確かめた資料は確認できず、推論です。
  • 根拠の種類：個人の経験則
  • 判断の位置づけ：推論を含む提案
  • 実行例：旅行の写真投稿で、1枚目を風景だけの写真から「京都 半日で回れる3か所」と文字を入れた写真に変え、2〜4枚目を1か所ずつにする（提案であり、成果が確認された例ではありません）。
  • 条件や限界：写真投稿向け。「何枚が最適か」は根拠を確認できず、示しません（T31）。画像を作る手間がかかります。
  • 対応する公式出典：直接の公式出典なし

C8 続きもの化

  • 理由：見る人の過去の視聴やいいねは、その人へのおすすめに反映されます（S1）。ある投稿をよく見た人に近い題材を続けて出せば、関心の合う人に届きやすいと考えられます。ジャンルを一つに絞らないと配信されない、という根拠はありません（T21）。
  • 再生数へのつながり：間接。続きものにすること自体の効果を測った資料は確認できず、推論です。
  • 根拠の種類：個人の経験則
  • 判断の位置づけ：推論を含む提案
  • 実行例：（動画の例）「100円の道具で掃除」の動画がよく見られたら、同じ構成のまま場所を変えた「浴室編」「玄関編」を出す（提案であり、成果が確認された例ではありません）。
  • 条件や限界：おすすめの説明（S1）は形式を限っていないため「両方」としましたが、動画でも写真投稿でも、効果の実測は確認できていません。同じ動画ファイルや同じ画像をそのまま出し直すこととは別です（T24）。
  • 対応する公式出典：直接の公式出典なし

補足（順位には含めません）

効果の確かめ方

  1. 比べるのは自分の投稿同士だけにし、動画は動画と、写真投稿は写真投稿と比べます。動画は長さ、写真投稿は枚数が近いもの同士で見ます。
  2. 投稿からの経過時間をそろえます（例：どちらも投稿から7日後の数字）。投稿直後の数字では比べません。
  3. 動画で見る指標は、再生数、平均視聴時間、最後まで見た人の割合です（S9。私が取得できた本文の表記で、いまの画面の名称は異なる場合があります）。写真投稿は、動画と同じ指標が出るか確認できていないため、投稿ごとの再生数と、画面で実際に確認できた指標だけを使います。
  4. 1回に変える点は1つにします。2〜3件の差で「効いた」と決めません。合格ラインになる共通の数字はありません。

再生数が落ちたとき

  • 通知を確認します。違反があった場合は、アプリ内の通知で知らされます（S8）。
  • 投稿がおすすめの対象外になった場合は、その投稿の分析画面に通知が出て、理由の確認と異議申し立てができます。この通知を見るには、分析機能をオンにしておく必要があります（S8の英語版）。
  • アカウントの状態は「Account check」で確認できます（S8の英語版、S10）。日本語の画面での名称は確認できていません。
  • どれにも当てはまらなければ、制限ではなく、その投稿への反応の結果である可能性を先に考えます。再生数が急に落ちたことだけでは、制限とは判断できません（T29）。公式は、投稿の成績が数日かけて伸びる場合があるとも説明しています（S40）。
  • 「数日投稿を止める」「アプリを入れ直す」など、制限を解除する裏技として出回る方法は、公式に確認できないので勧めません。

写真投稿との使い分け

  • 事実として言えること：再生数で比べた第三者の集計では、動画のほうが写真投稿より多い傾向で、写真投稿のほうが多いとする比較可能な根拠は確認できませんでした（T30）。観測された傾向であり、同じ題材を形式だけ変えた比較ではありません。写真投稿の数え方が動画と同じかどうかも、公式に確認できていません。
  • 方針（推論を含む提案）：動画を軸にし、写真投稿は題材で選びます。
  • 動画に向く内容：動き、音、話し方そのものが内容になるもの（作る過程、実演、変化の前と後、語り）。
  • 写真投稿に向く内容：見る人が自分の速さで読んだり見比べたりしたいもの（手順、一覧、比較、文字で伝える情報）。これは形式の性質（S12）からの推論で、再生数で確かめられたものではありません。
  • 同じ題材を両方の形式で出す必要はありません。題材ごとに形式を選んでください。両方の形式を使うこと自体で配信が有利になる、という根拠は確認できていません。
  • 一方の助言を他方に当てはめられない点：C1・C2・C6は動画の視聴についての説明にもとづくため、写真投稿にそのまま当てはまるとは言えません。C5は動画での返信、C7は写真投稿だけの提案です。
  • 重点を移す条件：自分の似た題材の投稿で、同じ経過日数の再生数を比べ、写真投稿のほうが多い状態が続くなら、写真の比率を上げます。撮影や、顔・声を出すことが難しい場合に写真投稿から始めるのは、再生数の優劣とは別の、実践上の理由として成り立ちます。
